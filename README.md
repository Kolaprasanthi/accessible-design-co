# Accessible Design Co.

A responsive, accessible website for a fictional design studio. It highlights the company’s values and services and includes a contact form.

## View the Website

Keep these files together in the same folder:

- `index.html`
- `styles.css`
- `script.js`

Open `index.html` in a web browser. No build tools are required.

## Features

- Semantic HTML sections and headings
- Responsive navigation and layouts using Flexbox, CSS Grid, and media queries
- Keyboard skip link and visible focus styles
- Accessible form labels, instructions, validation messages, and status updates
- Reduced-motion support
- Responsive service cards and contact form

The contact form is a demonstration. It validates input in the browser but does not send or store messages. Social media links are placeholders.

## Reflection

### 1. What accessibility challenges did you face, and how did you address them?

I wanted the page to work for people using keyboards and screen readers, as well as people viewing it visually. I used semantic HTML, a skip link, clear form labels, visible focus styles, and helpful validation messages connected to the relevant fields.

### 2. How did you ensure that your design was responsive and accessible to all users?

I used Flexbox for the navigation and CSS Grid for the page sections and service cards. Media queries adjust the layout for smaller screens. I also included accessible text alternatives, good contrast, and reduced-motion support.

### 3. What tools or resources did you find most helpful during this project?

MDN’s HTML and CSS references helped with page structure and layout. WebAIM’s contrast checker and browser keyboard-navigation tools helped me consider readability and accessibility.
